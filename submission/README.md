\# FieldSignal — Submission Evidence



This folder contains evidence used to support the FieldSignal hackathon submission.



\## Evidence



\- `01\_farmer\_attention.png` — Farmer-facing ATTENTION state.

\- `02\_farmer\_normal.png` — Farmer-facing NORMAL state.

\- `03\_insufficient\_evidence.png` — Safe abstention when evidence is inadequate.

\- `04\_real\_nasa\_validation.png` — Real 2026 NASA POWER validation.

\- `05\_ai\_value\_test.png` — Controlled multivariate Small-AI validation.

\- `06\_sms\_french.png` — Low-bandwidth French SMS-format demonstration.



\## Validation



`real\_nasa\_2026.json` contains the verified real-data inference for the representative Man/Tonkpi context.



`ai\_value\_test.md` documents the controlled comparison between FieldSignal and a simple univariate threshold.



Synthetic demonstrations are explicitly distinguished from observed environmental data.
